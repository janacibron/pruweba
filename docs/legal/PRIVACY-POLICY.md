# Privacy Policy

**Last Updated: July 6, 2026**

## 1. Information We Collect

### Account Information
- Email address
- Name (optional)
- Company name (optional)
- Billing information (processed by Stripe; we do not store credit card details)

### Usage Data
- API request counts and timestamps
- Claim metadata (subject, predicate, origin) — NOT claim content
- IP addresses (for rate limiting and abuse prevention)
- Browser analytics (pruweba.com only, via anonymous page views)

### Technical Data
- User agent strings
- Request latency metrics
- Error logs

## 2. What We Do NOT Collect

We do NOT:
- Store the content of your claims (the `object` field is not persisted for billing)
- Read or analyze your claim data
- Sell your data to third parties
- Use your data to train AI models
- Track you across other websites

## 3. How We Use Information

- **Service delivery:** Process your verification requests
- **Billing:** Calculate usage for invoicing
- **Support:** Respond to your inquiries
- **Improvement:** Aggregate anonymous metrics to improve performance
- **Security:** Detect and prevent abuse

## 4. Data Storage

- Attestation records are stored for the duration of your subscription
- Free tier attestations are purged after 24 hours
- Billing records are retained for 7 years (legal requirement)
- Server logs are retained for 30 days

## 5. Data Security

- All API communication is encrypted via TLS 1.3
- API keys are hashed at rest
- Claim content is not logged
- Access to production systems is restricted to authorized personnel

## 6. Your Rights

You have the right to:
- Access your account data
- Export your attestation records
- Delete your account and all associated data
- Opt out of marketing communications

Email privacy@pruweba.com to exercise these rights.

## 7. Third-Party Services

| Service | Purpose | Data Shared |
|---------|---------|-------------|
| Stripe | Payment processing | Email, billing address, payment method |
| Vercel/Netlify | Hosting (pruweba.com) | Anonymous page views |
| Sentry (optional) | Error tracking | Error logs, user agent |

## 8. Cookies

pruweba.com uses no tracking cookies. Session cookies may be used for API key authentication on the API endpoint.

## 9. Children

The Service is not intended for users under 13. We do not knowingly collect data from children.

## 10. Changes

Material changes to this policy will be communicated via email. Continued use constitutes acceptance.
