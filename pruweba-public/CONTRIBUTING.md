# Contributing to Pruweba

Thank you for your interest in contributing. Pruweba is source-available under the PolyForm Noncommercial 1.0.0 license.

## Important: Licensing

By submitting a contribution, you agree that:

1. Your contribution is your original work.
2. You grant Pruweba a perpetual, worldwide, non-exclusive license to use your contribution under the PolyForm Noncommercial 1.0.0 license.
3. Pruweba may relicense your contribution under a commercial license for paying customers.
4. You retain copyright of your contribution but grant the above rights.

## What We Accept

- Bug fixes for the landing page
- Documentation improvements
- SDK improvements (TypeScript, Python)
- Example integrations
- Non-functional improvements (accessibility, performance)

## What We Don't Accept

- Changes to the verification engine (proprietary — in private repo)
- Changes to the API server (proprietary)
- Features that replicate the commercial product
- Changes that remove or weaken license enforcement

## Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Ensure the site renders correctly
5. Submit a Pull Request

## Code Style

- Follow existing patterns
- Use semantic HTML
- Maintain accessibility standards (WCAG AA)
- Keep JavaScript minimal
- No frameworks or build tools without strong justification
